Echo 2.0 brings offline push-to-talk dictation to Linux and introduces a CLI, a new terminal interface, and guided setup.

## What's new

- **Linux support:** x64 builds with Wayland and X11 integration.
- **From a console app to a CLI:** launch Echo with `echooo`, configure it with `echooo setup`, and manage it through built-in commands.
- **New terminal interface:** recording status, a live sound meter, recognized text, and commands in one screen.
- **Guided setup:** choose your language, microphone, hotkey, model, and acceleration settings; download models from the wizard.
- **One-command installation:** install Echo from PowerShell or a Linux terminal.
- **Built-in updates:** download updates with `/update` and apply them with `/restart`. Where supported, updates download only changed files.
- **Localized interface:** English, Russian, Chinese, Spanish, and German.
- **Audio recovery on Windows:** improved recovery after sound device changes and Windows account switches.

## Get started

**Windows — PowerShell:**

```powershell
irm https://githubphobos.github.io/Echo/install.ps1 | iex
```

**Linux:**

```sh
curl -fsSL https://githubphobos.github.io/Echo/install.sh | sh
```

Then run `echooo` and follow the setup wizard.

See the [README](https://github.com/GithubPhobos/Echo#readme) for the demo, the `wget` installation command, model guidance, and troubleshooting.
